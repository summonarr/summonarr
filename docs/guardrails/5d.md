# Guardrail 5d

_Moved verbatim from CLAUDE.md. The id is a permanent address; CLAUDE.md keeps the headline and hard rules._

5d. **NEVER send a browser-supplied file path to Radarr/Sonarr's `ManualImport`.** The command's files come ONLY from the arr's own `/api/v3/manualimport?downloadId=` response, re-read when the admin confirms; the paths in the request body only SELECT among those rows (`manualImportFiles`, [arr-queue.ts](../../src/lib/arr-queue.ts)).

    Why:
    - ManualImport moves or hardlinks whatever path it is given into the library, on the arr's host. Passing a body path through turns an admin endpoint into "copy any file the arr can read into the media folders".
    - Re-reading also judges the download live: a file imported, deleted or re-matched since the dialog opened is not imported blindly (409 when nothing chosen is left).

    Rules:
    - Only MAPPED rows are sent (Radarr: a movie id; Sonarr: a series id and every episode id), each carrying back the quality, languages, release group and flags the arr detected — the arr UI's own shape — unless the admin corrected them.
    - **A correction names IDS; the OBJECTS come from the instance.** `applyImportOverride` ([arr-queue.ts](../../src/lib/arr-queue.ts)) writes the movie (`/api/v3/movie/{id}`), the series and its episodes (`/api/v3/series/{id}` + `/api/v3/episode?seriesId=`), the quality (`/api/v3/qualitydefinition`) and the languages (`/api/v3/language`) from what the instance returns, and throws `ImportOverrideError` → 400 with nothing sent for an id it doesn't have — an episode of another series included. NEVER forward a quality/language/movie object from the body: the arr would import a file labelled with whatever the browser claimed. A hand-picked quality gets a fresh revision (v1, not a repack). Load only the catalog the corrections need (`overrideNeeds`), bounded.
    - Sonarr v3's manualimport rows carry ONE `language` object, not `languages`; it is carried back as `language` (the arr's own object) or v3 stores the file as Language Unknown. v3 has no `/api/v3/language`, so no language correction is offered there — one sent anyway is a 400 (`ImportOverrideError`) with nothing sent.
    - The import AND the preview re-read the arr's rows and re-apply the corrections on the server; the preview's reprocess answer is display only and never feeds the command.
    - The audit (`ARR_QUEUE_IMPORT`) records the download id, the file count, the mode and how many files were corrected — never paths. `tests/arr-ops-routes.test.mts` pins that an injected path and an injected quality object never reach the command and that each unknown id is a 400 with no command, mutation-verified.
