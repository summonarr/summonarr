# Missing

_Moved verbatim from CLAUDE.md "Core architecture"._

**Missing** — [src/lib/arr-missing.ts](../../src/lib/arr-missing.ts) (pure rules) + [arr-missing-data.ts](../../src/lib/arr-missing-data.ts) (live listings), page `/admin/missing`, ADMIN-only, Sonarr and Radarr tabs.
- One live `/api/v3/series` or `/api/v3/movie` listing per configured instance of the active tab's service (guardrail 32); a failed instance is named, never read as "nothing missing". Nothing in Summonarr is written; the page paints its last answer at once and then reads live (guardrail 5h).
- Each row's Search (`POST /api/admin/missing/search`) re-judges the title live and queues exactly what is missing: Radarr `MoviesSearch`; for a series, `SeasonSearch` per season with 2+ missing and no file at all (season packs), one `EpisodeSearch` for the rest (`planSeriesSearch`). NEVER `SeriesSearch` — it also hunts upgrades in every season and spends indexer API hits nobody asked for. A title that gained a file since the page loaded is a 409 (`nothingMissing: true`), not an upgrade search. A Sonarr search-missing refused part-way answers 202 with the ids it did queue and an additive `partial: true` (counting only what was queued) — never a failure that drops them; refused on its first command it is still a failure.
- A movie is listed when it has no file and its PHYSICAL or DIGITAL release date has passed (cinema-only or undated movies never are). A series is listed when an aired, monitored, regular-season episode has no file — counted through `sonarrSeriesCompletion`, the guardrail-14a rule, never a private threshold. A row expands to its episodes on demand (`GET /api/admin/missing/episodes`, configured instances only).
- `monitored` is reported, not filtered on; the page hides unmonitored titles by default.
- **Cutoff unmet** is the page's second mode (`?mode=cutoff`): titles that HAVE a file below the quality profile's cutoff, from Radarr/Sonarr's own `/api/v3/wanted/cutoff` (monitored only), judged by the arr's `qualityCutoffNotMet` — never a quality comparison of ours (cutoff also weighs custom-format scores). Its Search re-judges live and queues an upgrade search for exactly that: Radarr `MoviesSearch`; one Sonarr `EpisodeSearch` for the monitored episodes whose file is below cutoff (`planCutoffSearch`). 409 when nothing is below cutoff any more. A listing past `CUTOFF_MAX_PAGES` × `CUTOFF_PAGE_SIZE` (40 × 500) records on an instance is reported `truncated` (named per instance, read of total, pointing at Arr System's library-wide cutoff search) — never read as the complete list.
